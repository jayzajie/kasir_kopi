# Kedai Kopi Karsa.co POS

Aplikasi kasir coffee shop berbasis Flutter. Target utama Android/iOS, dengan
target Windows untuk pengujian lokal.

## Menjalankan di Windows

```powershell
flutter pub get
flutter run -d windows
```

Build release tersedia dengan:

```powershell
flutter build windows
```

Executable hasil build berada di
`build/windows/x64/runner/Release/kasir_kopi.exe`.
